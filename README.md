# SiteEcho AI 

> An image description tool built for accessibility — upload any image and get a meaningful, human explanation of what's in it.

---

## Why I Built This

I wanted to build something that actually helps people. A lot of image tools just say "this is a cat" or "this is a building" — that's not useful for someone who can't see the image. SiteEcho tries to describe images the way a person would — with context, emotion, and meaning.

It's not perfect, but it works, and I learned a lot building it.

---

## What It Does

- Upload any image (JPG, PNG, WEBP)
- Get a warm, detailed description generated by LLaMA 4 via Groq
- Supports English and Hindi
- Saves your history to MongoDB
- Built with accessibility in mind — keyboard navigation, screen reader friendly

## Running Locally

### Requirements
- Python 3.10+
- Node.js 18+
- Free Groq API key from [console.groq.com](https://console.groq.com)
- Free MongoDB Atlas cluster from [cloud.mongodb.com](https://cloud.mongodb.com)

### Backend
```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
pip install httpx
```

Create `backend/.env`:
```env
MONGO_URL=your_mongodb_atlas_url
DB_NAME=siteecho
GROQ_API_KEY=your_groq_key
CORS_ORIGINS=http://localhost:3000
```

```bash
python -m uvicorn server:app --reload --port 8000
```

### Frontend
```bash
cd frontend
npm install --legacy-peer-deps
```

Create `frontend/.env`:
```env
REACT_APP_BACKEND_URL=http://127.0.0.1:8000
```

```bash
npm start
```

Open `http://localhost:3000`
